# 🐚 Kalinga Trails — Odisha Tourism

Explore the soulful beauty, rich heritage, and vibrant culture of **Odisha** (Kalinga). This project is a high-end, interactive tourism landing page designed to provide a seamless user experience while showcasing the "Best Kept Secret of Incredible India."

![Kalinga Trails Preview](https://github.com/NilambarSonu/kalinga-trails/blob/main/assets/preview.jpg?raw=true) *(Note: Add a preview image to your assets folder for this to work)*

---

## ✨ Features

- **Interactive Konark Wheel**: A unique, physics-driven interactive component in the hero section that symbolizes the passage of time and wisdom.
- **Glassmorphic UI**: Modern, premium design aesthetics with blur effects, smooth gradients, and elegant typography.
- **Scroll Reveal Animations**: Dynamic content loading as you scroll through Odisha's destinations, food, and culture.
- **Smart Booking Form**: A robust contact form integrated directly with **Google Sheets** for real-time lead management.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Micro-interactions**: Hover effects, smooth transitions, and a custom "Like" system using local storage.

## 🛠️ Technology Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+).
- **Integrations**: Google Apps Script (Backend for Form), Google Sheets (Database).
- **Fonts**: Inter & Outfit (via Google Fonts).
- **Icons**: Lucide Icons & FontAwesome.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/NilambarSonu/kalinga-trails.git
   ```
2. **Open the project**:
   Simply open `index.html` in any modern web browser.
3. **Google Sheets Integration**:
   - The contact form is connected via a Google Apps Script. 
   - To use your own sheet, replace the `scriptURL` in `script.js` with your deployment ID.
